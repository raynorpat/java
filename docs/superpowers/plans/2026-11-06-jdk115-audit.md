# Phase 1 quick audit and execution ledger

## Audit

- Task 3 cannot promise a working build after replacing ABI-defining headers. Treat Tasks 3 and 4 as one integration gate, with smaller subsystem checkpoints inside Task 4.
- Task 4 is a reconstruction milestone, not an implementation-sized task. Inventory binary evidence and boot dependencies before changing the interpreter, loader, natives and platform layer together.
- A blanket CTest WILL_FAIL accepts harness failures as success. Validate oracle files and executable prerequisites separately; track the known boot failure explicitly.
- Windows oracle bytes are not universally portable. Paths, properties, default encoding and process commands need platform-specific expectations or deliberately portable assertions.
- Define whether java_test ARGS are VM options or program arguments; classpath tests require options before the class name.
- Preserve the 1.0.2 classes archive before removing classsrc, including its install dependency. Do not delete the old javap test until its replacement runs.
- The verifier, thread/GC and JNI milestones may contain boot prerequisites for Task 4. Determine those dependencies from headers and binary evidence, rather than filling gaps with untracked stubs.
