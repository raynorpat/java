# JDK 1.1.5 JPEG implementation plan

Approved design explicitly permits unmodified IJG release 6 source. Inventory
confirms one export, the classic JPEGImageDecoder.readImage stub, with six VM
imports. Existing runtime/jpegdecoder.c is the retained Sun 1.0.2 starting point.

1. Stage IJG 6 (2-Aug-95) C/header source with archive hash and README license.
   Recover Sun 1.1.5 input, warning, error, cancellation and pixel behavior in
   Release/Debug DLLs, cross-checking Rhapsody names.
2. Add a headless native bridge that forwards the exact original stub to a
   Java test receiver implementing its callbacks. This exercises original
   decoder glue without constructing AWT peers or changing classes.zip.
   Generate deterministic color, grayscale and progressive fixtures with IJG.
   Capture original Sun pixel checksums, truncated/malformed input behavior,
   short reads, input exceptions, null arguments and callback cancellation.
3. Port the retained glue only where 1.1.5 differs. Build a standalone jpeg
   library exporting exactly the original stub, with no added VM exports.
4. Verify oracle output and export surface on Windows Release/Debug and
   C89/m32 Linux Release/Debug. Parent integrates the dedicated CMake fragment.

The Phase 2 boundary is image decoding and native callbacks. Rendering those
pixels in AWT windows remains a later milestone; no fake AWT is introduced.
