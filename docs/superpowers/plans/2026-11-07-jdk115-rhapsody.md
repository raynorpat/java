# Phase 7: Rhapsody DR2 implementation plan

> Use superpowers:executing-plans inline, with one fresh whole-branch review
> before completion. The owner authorized Phase 7 after merging Phase 6.

**Goal:** Build and run the reconstructed JDK and unchanged demo matrix on
Rhapsody DR2 Intel, including Apple's AppKit AWT.

**Architecture:** Preserve the 1.1.5 baseline archive and correctness fixes.
Use the recovered cthreads HPI, audit a separate AppKit peer archive, and recover
the Objective-C native implementation and JNI bridge from the Intel DR2 donor.
Real DR2 execution is required; host structural tests are only preflight.

**Tech stack:** C89, Objective-C/AppKit, Mach cthreads, JNI, CMake, Python audits.

**Spec:** ../specs/2026-11-06-jdk115-reconstruction-design.md (Phase 7).

Work branch: build/jdk115-rhapsody, existing workspace.

## Constraints and review focus

Keep original archives and donor binaries read-only and git-ignored. Never ship
donor native code as reconstructed output or edit demos to pass. Preserve Windows
and Linux regressions. PPC/Server 1.2 material is a cross-check, not Intel DR2 proof.

Review native/Java layouts and JNI handle ownership; cthreads suspend/GC interactions;
AppKit main-thread dispatch and callback reentrancy; graphics/image/font lifetime;
and modal/input/disposal ordering. Each owning task must exercise those paths.
